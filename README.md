# Sudoku

React Native + Expo (TypeScript, expo-router) Sudoku app with a hint system and technique training.
See `docs/PLAN.md` for the plan and `CLAUDE.md` for workflow.

## Run

```
npm install
npm start          # Expo dev server (scan with Expo Go)
npm run web        # run in the browser
```

## Checks

```
npm test           # jest (jest-expo)
npm run typecheck  # tsc --noEmit
npm run lint       # eslint + prettier config
npm run format     # prettier --write
```
